# Dilip Rathod — Portfolio

Personal portfolio site for Dilip Rathod, QA Automation Engineer. Plain HTML/CSS/JS, no build step.

## Structure

- `index.html` — page content
- `style.css` — styling
- `script.js` — nav toggle, scroll effects, animated stats
- `assets/Dilip_Rathod_QA_Resume.pdf` — downloadable resume

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
npx serve .
```

## Deploy to GitHub Pages

```bash
git push -u origin main
```

Then in the GitHub repo: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
The site will be live at `https://rathoddilip.github.io/dilip-portfolio/`.
